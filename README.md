# Diplomatic Path 🌍

**Diplomatic Path** is a personal learning platform for developing languages and international political knowledge.

## Languages

- 🇬🇧 English — A1 → A2 → B1 → B2 → C1 → C2
- 🇫🇷 French — A1 → A2 → B1 → B2 → C1 → C2
- 🇪🇸 Spanish — A1 → A2 → B1 → B2 → C1 → C2

All three languages start from **A1** inside the program and progress gradually based on performance.

## Main Areas

- 🏠 Personal dashboard
- 📚 Language learning: vocabulary, grammar, reading, listening, writing, and speaking
- 📰 Daily international and political news
- 🏛️ Political knowledge
- 🌍 International relations
- 🗺️ Geopolitics
- 🪖 Defense and security concepts
- 🤝 Diplomacy and international organizations
- 🗣️ Political and diplomatic simulations
- 🧠 Quizzes and review
- 📊 Progress tracking
- 🎯 Personal goals
- 🔥 Streaks and XP

## Learning Approach

News and international topics will be used as learning material across the three languages. English, French, and Spanish will gradually include political vocabulary, diplomatic terminology, and political discussions appropriate to the learner's level.

## Roadmap

1. Build the first dashboard and language-learning foundation.
2. Add A1 learning content for English, French, and Spanish.
3. Add quizzes, progress tracking, and daily goals.
4. Add political knowledge, geography, and international relations.
5. Add daily news with reliable sources and dates.
6. Add political and diplomatic simulations.
7. Add AI-assisted practice and personalized learning.
